# Usage des actifs de marque VERALUZ

## Hiérarchie validée

| Actif | Rôle | Usages autorisés | À éviter |
|---|---|---|---|
| Monogramme `VR` doré sur Atlantique | signature compacte | icône PWA, favicon, avatar, sidebar compacte | longs documents, très petite impression monochrome |
| Blason doré Résidence VERALUZ | identité premium principale | login, accueil, Guest Portal, entêtes de documents premium | répétition sur chaque carte |
| Blason monochrome | variante technique | photocopie, reçu thermique, tampon, impression économique | surfaces marketing couleur |
| Blason coucher de soleil | expression éditoriale | marketing, réseaux, accueil Guest avec contexte visuel | thème général de l'OS, sidebar, tableaux métier |

## État du dépôt

`assets/veraluz-logo.png` contient actuellement la version coucher de soleil. UI-0 ne remplace pas ce fichier et ne modifie aucun écran.

Avant une intégration globale, préparer des actifs de production :

- fonds transparents ;
- dimensions normalisées ;
- SVG propre quand la source le permet ;
- variantes claire/sombre ;
- tailles PWA complètes ;
- validation humaine du rendu final.

Les fichiers raster de référence peuvent guider un agent, mais ne doivent pas être vectorisés, recolorés ou redessinés automatiquement sans validation de Blaise.

## Identité textuelle

- Nom produit interne : **VERALUZ OS**.
- Marque d'hébergement : **Résidence Veraluz**.
- Slogan marketing : **Là où la lumière rencontre la mer.**
- Devise financière : `XAF` / affichage utilisateur `FCFA` selon le contexte existant.
- Langue principale : français ; prévoir l'extensibilité multilingue sans mélanger les libellés dans UI-0.
